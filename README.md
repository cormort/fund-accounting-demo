# 中央與地方作業基金會計系統 Demo（靜態版）

純前端展示版，所有資料存在瀏覽器 localStorage，每位使用者各自一份；按右上「重設資料」還原展示資料。

## 功能
- 中央／地方、多基金與實績單位
- EAS 示範科目主檔
- 借貸平衡傳票（檢核借貸平衡、單位歸屬、科目有效性）、送審、過帳、反沖
- 預算執行及可用餘額

> 本專案是展示及需求驗證版本，不應直接用於正式公務記帳。

## 本機執行
直接開啟 `index.html`，或 `python3 -m http.server` 後開 `http://localhost:8000`。
