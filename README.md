# 地方教育發展基金會計 Demo（靜態版）

依教育部「地方教育發展基金會計制度（參考範本）」及預算籌編操作手冊製作的純前端展示版。所有資料存在瀏覽器 localStorage，每位使用者各自一份；按右上「重設資料」還原展示資料。

## 功能
- 分預算基金：教育局(處)、所屬學校，可個別或彙總檢視
- 會計科目：平衡表科目、基金來源、基金用途（工作計畫）＋用途別科目
- 收入／支出／轉帳傳票：檢核借貸平衡、傳票種類與現金科目、用途別（經常門／資本門）
- 送審、過帳、反沖（另開沖銷傳票）；過帳時做預算控制，超出可用預算即擋下
- 報表：平衡表、基金來源用途及餘絀表、預算執行
- 預算籌編：基金來源明細表、基金用途明細表、預計平衡表（含來源＝用途、資產＝負債＋基金餘額檢核）

> 本專案是展示及需求驗證版本，不應直接用於正式公務記帳。

## 本機執行
`python3 -m http.server` 後開 `http://localhost:8000`。

推送到 GitHub `main` 時，GitHub Action 會同步到 Hugging Face Space（需設定 `HF_TOKEN` secret）。
